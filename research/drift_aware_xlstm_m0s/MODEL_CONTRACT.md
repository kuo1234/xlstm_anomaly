# Predictive model / full state contract

This is a new encoder-only one-step forecasting track. No existing reconstruction checkpoint is used. Observation x_t passes through an input projection, two-block causal recurrent core, and a linear prediction head for x[t+1]. The model API is forward(observations) or step(one_observation,state); neither accepts labels, regime truth, boundary, anomaly metadata or thresholds.

xLSTM is pinned xlstm2.0.5 vanilla float32: embedding16, `[sLSTM,mLSTM]`, four heads, causal kernel4, no FFN. sLSTM state `[4,B,16]` contains y/c/n/m and conv tuple `[B,4,16]`; mLSTM inner32 gives C `[B,4,8,8]`, n `[B,4,8,1]`, m `[B,4,1,1]` and conv tuple `[B,4,32]`. All dictionary keys/tensor shapes are audited. Layer norms/projections/skip parameters are frozen, not hidden history. Native layer.step calls scalar cell.forward; the suspicious low-level scalar-cell.step return is avoided. Stack.step mutates state dictionary and convolution storage, so every counterfactual branch uses a deep tensor/container copy. Full reset means native `None` for the entire core, never reset_parameters or partial h/c zeroing.

Matched two-layer LSTM H20 has `(h,c)` shapes `[2,B,20]`, projected E16 inputs and H20→E16 readout. Counts xLSTM6832, LSTM7016 (2.69% difference). Both objective/training/update schedules match. Extra projections and native cell design imply imperfect architecture matching, explicitly disclosed; no backbones are added after observing results.

Inference clock: prefix last output is issued before suffix x0 and scored against x0. KEEP consumes x0 with carried state; evaluator-scheduled oracle RESET consumes x0 from complete initial state. The x1 forecasts diverge but x0 forecast/score cannot be revised. There is exactly one new observation ingestion per arm per target; only the explicitly named FIXED-L replay recomputes past context. Scores average standardized squared residual across eight channels; they are instantaneous one-step target scores, not window scores. Missing/abstained scores are not inserted; prefix128 supplies every suffix target, including offset0.

Every training sequence calls forward with fresh state; x[t+1] targets stop at its own final sample. Epoch batches can contain both regimes but no state is shared between batch rows. Model selection uses stationary validation objective only, with fixed warmup8. Test/scaler/calibration stay separate. eval disables dropout; requires_grad(False), inference_mode and model parameter/all-buffer hash checks enforce frozen test weights. No optimizer is created in inference. Scaler never updates at a boundary. Alarm threshold, if needed, is one scalar per model fit from separate stationary calibration, shared across arms.

Random full/step tolerances fixed atol1e−5/rtol1e−4; exact chunk/snapshot equality separately required. Native context mask capacity384 covers every sequence/replay length in this protocol. There is no padding, ragged batch or heterogeneous per-row reset. All rows in one arm reset together; each group has equal sequence lengths. Batching and per-stream independence are audited. Scientific checkpoints receive the same random fixture audit before held-out evaluation; complete-state/future-prefix/frozen-weight failure stops execution. Tests are API evidence, not scientific mechanism evidence.
