# Adversarial review

Status applies to the proposed scientific claim, not an observed performance result. All falsification experiments below remain conditional on new authorization. Current evidence is static inspection and the bounded random API fixture only.

| Attack | Status | Assessment and smallest discriminating test |
|---|---|---|
| 1. Existing xLSTMAD has no cross-window stale state | **FATAL** to an unchanged-xLSTMAD claim | Verified fresh window calls. A carry experiment must be separately named; first demonstrate full-state carry with one ingestion per point (API fixture passes mechanics only). |
| 2. Reset gain is only short context | **RESOLVABLE** | Reset literally truncates history. Compare incompatible vs compatible equally long remote prefixes with identical recent suffix; add fixed-L replay and periodic/count-matched reset. If short context accounts for gain, drop memory-specific novelty. |
| 3. LSTM/GRU suffice | **NOVELTY_THREAT** | No evidence xLSTM is necessary. Match input/forecast/calibration/training/compute budgets and state policy. Equivalent interaction in ordinary recurrent models defeats xLSTM specificity. |
| 4. Drift detector contributes everything | **RESOLVABLE** | Use oracle-boundary resets only as an upper bound, and the same causal trigger for each intervention/backbone. If trigger-only baseline explains benefit, do not claim new state mechanism. |
| 5. Anomaly triggers reset and suppresses alarms | **RESOLVABLE** | Test isolated and sustained anomalies, shifts without anomalies, and mixed events. Keep current scores immutable; report post-reset recall and false resets, not just recovery. Observations alone do not certify benign drift. |
| 6. TSB lacks exact shift boundaries | **SCOPING_LIMITATION** | Recovery claim is untestable on inspected release. Restrict TSB to auxiliary anomaly metrics; controlled independently annotated shifts are required. If real recovery is a mandatory claim, this becomes FATAL until annotations exist. |
| 7. Stateful forecast deviates from paper | **SCOPING_LIMITATION** | Improved release has reconstruction only. Separate a new encoder-predictive track and retain original named baseline. Never describe new training/head/carry as unchanged reproduction. |
| 8. Full state capture is unclean | **RESOLVABLE** | All model states defined; deepcopy/serialization suffix test passes. Mutable conv buffers and dictionary aliases are real hazards. Optimized kernels, long streams and heterogeneous row resets remain unverified. |
| 9. Prior art already does this | **NOVELTY_THREAT** | HSO/TTT/Leto/RSI/forgetting invalidate broad frozen-weight state-adaptation novelty. Resolve direct reset/RSI full text and claim-level differences before any method pitch. Exact task collision remains unknown, not absent. |
| 10. Weights are wrong, state is not stale | **FATAL** to interpretation without control | Require the same frozen weights to predict B under compatible B history using a predeclared adequate-fit criterion. If they fail both histories, reset cannot identify state-specific mismatch. |
| 11. Reconstruction is identity-like | **RESOLVABLE** | Target enters current projection/residual paths. Compare a future authorized one-step predictive objective and identity/last-value controls. No historical reconstruction checkpoint may masquerade as a forecaster. |
| 12. Carry horizon is out of training distribution | **RESOLVABLE** | Compare stationary long-run carry and fixed horizon before drift. A universal long-run deterioration is execution/training mismatch, not drift-specific staleness. Nonzero random weights do not resolve this. |
| 13. Normalizer or convolution transients explain gain | **RESOLVABLE** | Hold scaler fixed; predeclare normalization-only, conv-only and complete-reset controls. If conv reset suffices, narrow the mechanism accordingly. |
| 14. Warmup/abstention hides errors | **RESOLVABLE** | Keep the same evaluation timeline; count unscored timestamps, alarm loss and reset/warmup latency. No future-score backfill. Censor unresolved recovery explicitly. |
| 15. State distance is itself changed by reset | **FATAL** to unqualified state-distance outcome | Use independent forecast residual/detection endpoints; a smaller distance after clearing memory proves nothing. |
| 16. Data provenance/dependence inflates evidence | **SCOPING_LIMITATION** | Historical TSB bytes include simulations, unresolved native identities and duplicate source groups. Preserve exclusions/family-first inference and distinguish current download status. |
| 17. Search abstention becomes a novelty claim | **NOVELTY_THREAT** | Inaccessible thesis/RSI/I-LSTM/RC-Mamba and Leto metadata remain explicit. No search can certify novelty by absence; reviewer must resolve closest methods or narrow claim. |
| 18. Hidden-state adaptation implies safe admission | **FATAL** to safety/normality claim | Residual persistence cannot distinguish all benign and harmful regime changes. This work must not revive the stopped Safe Admission claim; require external semantics for that separate objective. |

No item is marked NOT_A_PROBLEM merely because a random numerical check passed. The simplest next scientific question is whether incompatible history causes any harm that a matched short-context baseline cannot already explain. Failure there is a reason to stop, not to add a learned controller, state bank or RL.
