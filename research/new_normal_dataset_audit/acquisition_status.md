## Provenance practice for any later acquisition

Before using a candidate, record the publisher DOI/version, exact file list and byte sizes, checksums, download date, license text for the data itself, preprocessing code/version, raw entity/stream IDs, original split, and every derived-file checksum. Do not treat a code repository license as the dataset license. Do not replace unavailable sources silently. For a huge source, first decide whether a documented subset is sufficient and whether its selection is independent of model outcomes.
