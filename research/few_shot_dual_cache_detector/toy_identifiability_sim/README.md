# Toy 模擬：自我確認 cache 規則的可識別性

- 目的：檢驗「殘差大的區段先進可疑 cache，持續夠久就升格為正常」這條規則在不同情境下的行為。
- 範圍：只用 CPU；純合成資料；**沒有使用任何真實資料或標籤**。
- 重現方式：`python sim.py`，會輸出 `results.csv`。本 commit 的 `results.csv` 與重跑結果逐欄一致（最大差異 0.0）。

## 設定

- 訊號：y = 2·c + AR(1) 雜訊（φ = 0.7，σ = 0.3）。c 是負載指令，有兩種設定：固定，或 0.3 振幅、週期 400 的正弦波。
- 前 1000 步訓練，之後部署；事件在 t = 1500 發生。
- 分數：殘差的 EWMA（span 20），以訓練期統計量標準化，閾值 4。
- 升格規則：可疑區段持續 ≥ 150 步（容許 ≤ 10 步的中斷）就升格，用最近 300 步重新擬合。
- S1 使用以 16 個 y lag 為輸入的 ridge 一步預測器，代表 forecasting 偵測器（例如 xLSTMAD-F）。S2 和 S3 使用以 c 為輸入的正常行為模型。

## 情境

A 短暫尖峰故障、B 短暫良性測試、C 永久的良性設定點改變、D 感測器偏移故障（y 與 C 逐點相同）、E 緩慢劣化、F 長時間故障後修復。

## 主要結果

- C 和 D 的 y 最大差異為 8.9e-16。任何只看 y 的規則，在這兩個情境中必然輸出相同，所以必定錯一個。
- 週期負載設定下的故障召回率：

| 策略 | A | D | E | F |
|---|---|---|---|---|
| S1 | 0.95 | 0.01 | 0.00 | 0.02 |
| S2 | 0.85 | 0.10 | 0.25 | 0.38 |
| S3 | 0.85 | 0.98 | 0.50 | 0.96 |

完整數字（兩種負載設定、正常段誤報率、升格次數、是否吸收故障）請見 `results.csv`；`figure.png` 是對應的圖。

## 限制

- 只有單一訊號通道，模型也是線性的，只能用來說明機制，不能代表實際效能。
- 真正的驗證需要在 GB10 上用 xLSTMAD-F 和 repo 的合成資料產生器重跑。
