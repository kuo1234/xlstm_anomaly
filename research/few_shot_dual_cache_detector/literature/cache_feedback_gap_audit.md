# Gap Audit: Cache-Based Adaptation and Feedback-Driven Detector Updating for Time-Series Anomaly Detection

Search date: 2026-09-29. Sources: OpenAlex (keyed API), arXiv API, CrossRef, Unpaywall/Semantic Scholar/PMC via full-text fetch. All papers listed were verified by a real lookup this session (verification levels recorded per entry in `cache_feedback_papers.json`); none are cited from memory alone.

## 1. The cache-adaptation line (Tip-Adapter -> TDA/DMN/DPE/BoostAdapter) is mature, but confined to CLIP image classification

Tip-Adapter established the pattern the thesis design borrows: a training-free key-value cache built from a small support set, read by similarity-weighted voting and fused with a frozen backbone's zero-shot score, with an optional fine-tuned variant ("Tip-Adapter-F") that unfreezes the cache keys ([Zhang et al. 2022](https://doi.org/10.1007/978-3-031-19833-5_29)). The 2024 successors sharpen this in ways directly relevant to the thesis's normal/fault split: TDA maintains two online caches, one populated by low-entropy self-generated pseudo-labels ("positive") and one populated by samples in a mid-confidence band tagged with a multi-hot mask of classes they are NOT ("negative"), both read jointly with the frozen CLIP score at every test step with no backward pass ever taken ([Karmanov et al. 2024](https://arxiv.org/abs/2403.18293)). Dual Memory Networks generalizes the read operation from a similarity vote to an attention-style weighted readout and separates a curated "static" memory from an accumulating "dynamic" one ([Zhang et al. 2024](https://arxiv.org/abs/2403.17589)). Dual Prototype Evolving goes a step further and lets the stored prototypes themselves drift with incoming test data rather than simply accumulating entries, which is the vision-language analogue of absorbing benign distribution drift into a cache rather than treating every new sample as a candidate anomaly ([Zhang et al. 2024](https://arxiv.org/abs/2410.12790)). BoostAdapter improves cache population quality itself by bootstrapping additional pseudo-samples from regional image crops before admission (Zhang et al. 2024, arXiv:2410.15430).

The structural parallel to the thesis's L0 fused-score design (frozen backbone score + cache kNN evidence) is close: TDA's positive cache plays the role of the normal cache, its negative cache plays a role analogous to using confirmed non-fault evidence to suppress false hypotheses, and DPE's prototype evolution is the vision-language analogue of the "aging absorbed as new normal" requirement. The decisive difference is the supervision signal. Every one of these methods populates and prunes its cache from the model's *own* pseudo-labels and entropy at test time; none of them is driven by an asynchronous, delayed, human-confirmed feedback channel, and none has a notion of quarantining an unconfirmed sample pending later confirmation. They are also all closed-set multi-class image classifiers operating on i.i.d. test streams, not open-ended anomaly detectors on sequential machine signals where the "correct" label for a novel pattern is genuinely unknown until an operator inspects it.

## 2. Few-shot visual anomaly detection with small memories addresses AD, but not the dual-cache-plus-feedback combination

A second, closely related line applies CLIP-style memory to anomaly detection specifically, rather than classification. WinCLIP's few-normal-shot variant stores CLIP features of a handful of provided normal reference images and compares test patches to them via multi-scale similarity ([Jeong et al. 2023](https://doi.org/10.1109/cvpr52729.2023.01878)) — a normal-only reference memory, with no fault cache and no feedback loop. InCTRL trains one generalist detector across many source datasets and then, at deployment on an unseen target, reads a small non-parametric memory bank built from a handful of in-context normal exemplars with no gradient update on the target ([Zhu & Pang 2024](https://doi.org/10.1109/cvpr52733.2024.01688)) — the closest published match to "pretrain once, freeze, adapt via memory at few-shot commissioning" outside of time series, but again lacking a confirmed-fault cache, a feedback loop, or any drift-absorption mechanism. PromptAD, by contrast, found that a purely memory/prompt-frozen approach adapted from many-class prompt learning did *not* work for one-class few-shot anomaly detection and had to introduce learned (tuned) prompt pairs with synthesized pseudo-anomalies ([Li et al. 2024](https://doi.org/10.1109/cvpr52733.2024.01594)) — indirect evidence that cache-only adaptation can be insufficient once the target task shifts from closed-set classification to open-ended anomaly scoring, which bears on the thesis's core research question of when cache-only suffices. AnomalyCLIP and MuSc represent the opposite extreme: no target-specific memory at all, either via a single object-agnostic learned prompt (Zhou et al. 2023, arXiv:2310.18961) or via mutual scoring within an unlabeled test batch ([Li et al. 2024](https://arxiv.org/abs/2401.16753)). None of these five methods is evaluated on time series, and none incorporates human feedback.

## 3. Open-set supervised anomaly detection generalizes seen faults to unseen ones, but by training, not by a live cache

DRA decomposes an anomaly score into seen-anomaly, pseudo-anomaly, residual, and normal-class components so that a detector trained on a handful of seen fault classes generalizes to fault types never seen in training ("gray swans" the model was trained on vs. "black swans" it wasn't) ([Ding et al. 2022](https://arxiv.org/abs/2203.14506)). This is the closest match in the literature to the thesis's requirement to handle "new, previously unseen anomaly types after deployment," but the generalization is baked into fixed weights at a single training time; there is no online-growing cache, no post-deployment update, and the evaluation is on industrial *images* (MVTec-AD, fabric/PCB/solar-cell defect sets), not on sequential sensor signals. This line remains active: Anomaly Heterogeneity Learning (Zhu et al. 2023, arXiv:2310.12790) explicitly models variance among seen anomaly classes to sharpen the seen/unseen boundary, and two 2025-2026 preprints replace DRA's unimodal-Gaussian normal prior with, respectively, a diffusion-based prototype distribution (arXiv:2502.20981) and a flow-matching mixture-prototype model (arXiv:2605.02438), both still targeting the same seen-to-unseen generalization problem in the image domain with trained (not test-time-cached) weights.

## 4. Feedback-driven anomaly-score updating is an established but separate line from caching

A distinct thread updates a detector from sparse human feedback but does so by re-weighting the scoring function or retraining the base model, never by writing to a non-parametric cache. Active Anomaly Discovery re-ranks a tree-ensemble's anomaly scores after each analyst label by an online linear-model update over ensemble-member weights ([Das et al. 2016](https://doi.org/10.1109/icdm.2016.0102)); its successor reformulates the same feedback-incorporation problem as online convex optimization for a simpler, more efficient update rule, with a case study on reducing analyst effort to find red-team attacks in system audit logs ([Siddiqui et al. 2018](https://doi.org/10.1145/3219819.3220083)). DeepLog is the earliest of this group to touch time-adjacent data (system-call log sequences): when an operator marks a flagged sequence as a false positive, the underlying LSTM is incrementally retrained on the confirmed-normal sequence rather than the feedback being discarded ([Du et al. 2017](https://doi.org/10.1145/3133956.3134015)). Deviation Networks and its reinforcement-learning successor tackle a related but distinct problem — training a scoring head end-to-end from only a handful of labeled anomalies — again via weight updates, not a cache (Pang et al. 2019, doi:10.1145/3292500.3330871; Pang et al. 2020, arXiv:2009.06847). A 2024 ICDE system demonstration confirms that "interactive time-series anomaly detection" work at this search depth is largely about visualization and exploration of detector output for a human analyst, not a closed loop that updates the detector's cache or weights from the analyst's actions ([Boniol, Paparrizos & Palpanas 2024](https://doi.org/10.1109/icde60146.2024.00409)). None of this group maintains a dual normal/fault cache, and none has an explicit quarantine state for feedback that has not yet been confirmed one way or the other.

## Gap verdicts

### G4b — Dual cache (normal + fault) for TS anomaly detection updated from sparse, delayed operator feedback, with quarantine for unconfirmed data
**Verdict: PARTIALLY_OCCUPIED.** Every individual ingredient of this design is occupied somewhere, but never together and never for time series. The dual-cache *mechanism* is occupied by TDA and DMN (vision, self-supervised pseudo-labels, no quarantine). The *feedback-driven update* half is occupied by AAD, Siddiqui et al., and DeepLog (tabular/log data, weight re-scoring or retraining, no cache, no quarantine). The *seen-fault-generalizes-to-unseen-fault* half is occupied by DRA and its 2023-2026 successors (image data, trained weights, no online cache). No paper combines a growing normal+fault dual cache with an asynchronous, human-confirmed feedback signal and an explicit quarantine mechanic, for any data modality, let alone time series. Blocking/nearest papers: TDA (arXiv:2403.18293), DMN (arXiv:2403.17589), AAD (doi:10.1109/icdm.2016.0102), Siddiqui et al. (doi:10.1145/3219819.3220083), DeepLog (doi:10.1145/3133956.3134015), DRA (arXiv:2203.14506).

### G4c — Head-to-head L0 (cache-only) vs. L1 (cache + light tuning) vs. L2 (adapter/weight update) comparison for TS anomaly detection under matched feedback budget, with an adaptation-harm/false-absorption metric
**Verdict: OPEN_AT_SEARCH_DEPTH.** No dedicated cross-method comparison at matched label/feedback budget was found in *any* domain, and no paper reporting an adaptation-harm or false-absorption metric (the cost of accepting a wrong adaptation, as distinct from aggregate accuracy) was found anywhere. The only available signal is indirect and weak: Tip-Adapter, TDA, DMN, and DPE each report a training-free variant against a self-fine-tuned "-F" variant of themselves on the *same* closed-set image-classification benchmark, which is a same-paper self-comparison, not an independent matched-budget study, and carries no adaptation-harm metric. PromptAD's finding that off-the-shelf many-class prompt learning fails for one-class few-shot anomaly detection is suggestive that cache/prompt-only adaptation can break down outside classification, but is not a controlled L0/L1/L2 study either. Queries run (11, listed in `cache_feedback_papers.json`/output) returned no on-topic paper. Nearest papers: Tip-Adapter/Tip-Adapter-F (doi:10.1007/978-3-031-19833-5_29), TDA (arXiv:2403.18293), DMN (arXiv:2403.17589), DPE (arXiv:2410.12790), PromptAD (doi:10.1109/cvpr52733.2024.01594).

### G4g — Transfer of Tip-Adapter/TDA-style cache adaptation to time-series (or machine-signal) anomaly detection at all
**Verdict: OPEN_AT_SEARCH_DEPTH.** Eleven OpenAlex relevance queries and four arXiv title/abstract-field queries targeting this exact combination — cache-based test-time adaptation for time series, key-value memory for time-series anomaly detection, retrieval-augmented time-series anomaly detection, non-parametric memory-bank drift adaptation, kNN-memory industrial anomaly detection, prototype-based test-time adaptation for time-series classification — returned only unrelated surveys (edge computing, IoT, federated learning, generic deep-learning reviews) with no full-text or abstract match to a time-series/machine-signal application of the Tip-Adapter/TDA/DMN/DPE cache mechanism. The entire identified cache-adapter line (Tip-Adapter, TDA, DMN, DPE, BoostAdapter) is confined to CLIP-based image/vision-language classification; the few-shot visual industrial-AD line that *does* touch anomaly detection with small memories (WinCLIP, PromptAD, AnomalyCLIP, InCTRL, MuSc) is likewise confined to static images. This appears to be a genuine, unaddressed cross-modality transfer at the depth of search conducted.

## Closest competitors (method + evaluation reviewed in full text)

- **TDA** (Efficient Test-Time Adaptation of Vision-Language Models, CVPR 2024, [arXiv:2403.18293](https://arxiv.org/abs/2403.18293)): dual online positive/negative key-value caches populated from self-generated pseudo-labels/entropy, fused with a frozen CLIP zero-shot score, evaluated on ImageNet distribution-shift and 10 cross-domain classification benchmarks in a single streaming pass. Leaves open: any human-confirmed feedback channel, any quarantine of uncertain evidence, and any application beyond closed-set image classification.
- **DMN** (Dual Memory Networks, CVPR 2024, [arXiv:2403.17589](https://arxiv.org/abs/2403.17589)): static (curated) memory plus dynamic (test-time-accumulated) memory, read via an attention-weighted vote, unifying zero-shot/few-shot/TTA in one model, evaluated on the same benchmark family as TDA. Leaves open: the same feedback/quarantine/time-series gaps as TDA, plus a heavier per-query readout cost than a simple kNN cache.
- **DPE** (Dual Prototype Evolving, NeurIPS 2024, [arXiv:2410.12790](https://arxiv.org/abs/2410.12790)): textual and visual prototypes that evolve (rather than only accumulate) with incoming test-time data, evaluated on the same CLIP OOD/cross-domain suite. Leaves open: no mechanism to distinguish benign drift from a persistent fault signal, since "evolving toward the new distribution" is exactly the behavior a fault cache must NOT exhibit for a persistent fault.
- **Tip-Adapter / Tip-Adapter-F** (ECCV 2022, [doi:10.1007/978-3-031-19833-5_29](https://doi.org/10.1007/978-3-031-19833-5_29)): the foundational training-free cache + optional fine-tuned-cache design; evaluated on 11 few-shot image classification datasets. Leaves open: everything time-series/anomaly/feedback-related; it is the architectural ancestor of the whole line, not an anomaly detector.
- **InCTRL** (Generalist Anomaly Detection via In-Context Residual Learning, CVPR 2024, [doi:10.1109/cvpr52733.2024.01688](https://doi.org/10.1109/cvpr52733.2024.01688)): one model pretrained across many source AD datasets, frozen, then given a handful of in-context normal exemplars at test time on a new target dataset (memory bank + residual scorer, no gradient update); evaluated on 9 real-world image AD benchmarks. Leaves open: no fault cache, no feedback loop, no drift absorption, and images only.
- **DRA** (Catching Both Gray and Black Swans, CVPR 2022, [arXiv:2203.14506](https://arxiv.org/abs/2203.14506)): trains a detector on a few seen fault classes to generalize to unseen fault types via a four-component score decomposition; evaluated on MVTec-AD and several open-set defect-detection splits. Leaves open: generalization is trained once into fixed weights, not adapted online; images only.
- **AAD** (Incorporating Expert Feedback into Active Anomaly Discovery, ICDM 2016, [doi:10.1109/icdm.2016.0102](https://doi.org/10.1109/icdm.2016.0102)) and its KDD 2018 successor ([doi:10.1145/3219819.3220083](https://doi.org/10.1145/3219819.3220083)): online re-weighting of a tree-ensemble anomaly score from sequential analyst confirm/dismiss feedback, evaluated on tabular outlier benchmarks and (Siddiqui et al.) a red-team-attack case study. Leaves open: no cache at all — feedback updates the scoring function directly; no time-series evaluation; no quarantine state.
- **PromptAD** (CVPR 2024, [doi:10.1109/cvpr52733.2024.01594](https://doi.org/10.1109/cvpr52733.2024.01594)): learns normal/pseudo-anomaly prompt pairs from only normal few-shot images because a frozen/cache-only approach adapted from many-class prompt learning did not work for one-class few-shot AD; evaluated on MVTec-AD/VisA. Leaves open: still images; the finding that cache/prompt-freezing alone was insufficient is a data point for, not a resolution of, G4c.

## Threats to the "gap" claims

- Search depth is bounded by the query vocabulary tried; a paper using different terminology (e.g., "streaming few-shot" rather than "cache adaptation," or an industrial-specific venue not well indexed by OpenAlex's relevance ranker) could exist and not have surfaced.
- OpenAlex's free-text relevance search returned substantial off-topic noise for generic multi-word queries (surveys, unrelated ML reviews) even when narrowed; several queries for G4b/G4c/G4g returned zero on-topic hits out of 4-5 results, which is consistent with either a true gap or an indexing/ranking limitation of the tool used.
- arXiv's API rate-limited repeated title/abstract-field queries mid-session (HTTP 429); some candidate searches for G4g (e.g., "operator feedback" AND "anomaly detection") could not be completed on arXiv specifically and relied on OpenAlex coverage of arXiv preprints instead, which is not guaranteed to be as complete or as fast to index newly posted papers.
- Three papers (DRA's 2025/2026 successors) were verified only at abstract level via OpenAlex, with author lists not independently cross-checked against a second source; their existence supports "the open-set-AD line is active" but their specific claims are taken from the abstract only.
- Two papers (AAD, Tip-Adapter) could not be fetched in full text (no open-access copy located) and are verified at CrossRef/OpenAlex metadata level (title, authors, venue, year, DOI) plus, for Tip-Adapter, cross-reference with the well-known public GitHub implementation — not from a fetched abstract or body text.
