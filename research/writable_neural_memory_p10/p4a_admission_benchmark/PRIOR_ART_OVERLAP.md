# Prior-art overlap and decision semantics
Evidence scope: inspected official pinned code and primary papers. Absence claims mean not implemented in these inspected paths, not proof of absence from all literature.

| Method / inspected path | Effective change and sample gate | Delay / formal regime endpoint | Contamination / reversibility | Concrete overlap and limitation |
|---|---|---|---|---|
| M2N2, Exp/MLP.py online; models/Normalizer.py | Detrend EMA statistics consume current batch before inference; gradient masked by score threshold, updating network on predicted normal samples | Batch update; no segment PROMOTE contract or explicit quarantine | No operational rollback trigger in inspected loop | New Normal Problem and test-time adaptation already prior art. Normalizer mutations must count even for gradient-rejected points. Native inference/statistics ordering differs from future causal common track. |
| CANDI, predictor.py; tta/candi/adapter_candi.py | Hard high-score candidates selected by latent similarity to high-normal-score validation references; moderate candidates by intermediate-score references. Curated hard/moderate buffers drive SANA residual adapters (or configurable base-model adaptation) | MIN_SAMPLES=16 buffer trigger plus configured stages; no normative settled-regime commit | Code has anomaly-selected counters, including pending buffered points; these are not confirmed exposure/FAR. No implemented operational verify/rollback trigger | Selective adaptation, reference sets, delayed buffered updates and contamination counters already exist. A cache/delay/low FP claim alone is insufficient novelty. |
| CANDI bundled M2N2 adapter | Predictor scores first; adapter updates normalization, recomputes masked loss | Different ordering from official M2N2 native implementation | Requires explicit variant naming | Do not silently equate these implementations. |
| StrAD MemStream variant | Initial AE; kNN score then threshold-gated FIFO raw/latent memory, optional statistics update; inspected beta=.1 default | FIFO and score gate, no persistent-regime admission endpoint | Gate limits writes but no verified rollback protocol | Gated normal-reference memory is already prior art; this pin's kNN aggregate differs from original formulation. |
| StrAD MCOD / LEAP wrappers | Feed incoming samples into streaming detector state without anomaly rejection at wrapper | Native streaming/buffer updates; no formal admission | Underlying dependency ordering not fully established | Candidate aggressive-streaming controls, not proof that all internal states are identical or that every StrAD method updates unconditionally. |
| StrAD LODA wrapper | Integer-bin path rebuilds histograms on current input; auto-bin fit_partial path only computes scores | Bin-mode dependent | No legitimacy gate in integer-bin path | Cannot describe auto-bin LODA as unconditional updating: inspected implementation does not update those histograms. |
| StrAD adapter wrappers | PySAD fit_score_partial; postprocessed wrapper explicitly fit then score; dSalmon fit_predict | Native order varies by implementation | No normative truth / commit in wrappers | Must pin dependency versions and audit ordering before using common causal metrics. |

CANDI details that materially affect reproduction: full normal-validation covariance and chi-square lower quantile .05 are latent selection mechanics, not calibrated safety evidence. The moderate q1/q3 score mask is overwritten by below-threshold mask in inspected code. The hard reference set is high-scoring normal validation data, not labelled test anomalies. Labels appear in diagnostic anomaly-selected counters; they must never drive future adaptation. Buffer contents, nonzero-loss contributors and actual mutable-state exposures must be separated.

Safe delayed admission could be a narrower hypothesis only if it demonstrates false-normalization control with finite valid acceptance delay and preserved anomaly/old-normal retention. Explicit commit and rollback semantics are possible differences, not established novelty or success. Training fewer parameters is not itself safe admission.
