# Implementation obligations for a future task
These clarify the frozen semantic contract, not executed policy measurements or new tuned endpoints.

Do not treat ordinary valid A updates as false admission. FAR-admit numerator is only actual exposure of evaluator-negative anomaly/non-benign episode IDs. Settled-B PROMOTE admissibility is a separate stricter payload test: an all-clean B target cohort is needed. Transition or old-A IDs in a B-PROMOTE payload make that payload invalid for the target even if those points are source-benign; report separately from anomaly contamination purity. Baseline writes during a benign transition have temporal exposure status, not fabricated formal PROMOTE.

An actual normalization/optimizer mutation can happen without a memory write or nonzero gradient; audit all persistent paths. A buffer that is only queued is pending, while using its statistics to change effective normality already counts exposure. Native CANDI anomaly counters are not this ledger. Attribute window-level adaptation to contributing point IDs and active loss weights; do not automatically count every point in a zero-weight window as gradient exposure.

Physical seed is the independent unit. The three arms are paired; the semantic twin has one persistent negative episode after transition start, not a fresh independent failure each tick. Report denominators and no-write/censoring explicitly. FPR recovery remains a supplementary trajectory; any future scalar recovery criterion requires prospective reviewer approval, not post-result fitting.

P4-A contains no actual update ledger, online detector, formal-commit instrumentation or rollback experiment. Those are acceptance obligations of a future P4-B task. Native M2N2 pre-score EMA updates must be reported separately from a named score-before-all-mutations variant; silently rewriting its order would hide a baseline difference.
