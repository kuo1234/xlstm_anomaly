## Qualification and acquisition boundaries

TEP is not rescued by renaming an actuator, Mode1 identity or evaluator event table as context. P3-A range receipts remain the evidence; whole-HDF5 hashing was not completed. No new TEP bytes or 2015/2021 source substitution.

CWRU and Paderborn support condition-aware detection, not a real continuous A-to-B transition. Paderborn measurements keep operating parameters constant within each four-second record. Resampling must preserve actual measurement support and never nearest-future join. Concatenating records would produce a declared controlled splice, not observed causal field order.

C-MAPSS/N-CMAPSS can motivate L1 residual controls, not industrial authorization evidence. NASA's 2021 N-CMAPSS catalog identifies the journal release, but the acquired 2020 descriptor is a separate precursor: its nine-unit counts and traces are NOT substituted for 2021 bytes. No named N-CMAPSS raw subset is claimed verified. The NASA C-MAPSS simulator software notice is not a blanket claim that the FD dataset is inaccessible; the distinct FD catalog was acquired.

ESA deserves further qualification rather than rejection. Anonymized command identity does not provide a recipe/target meaning or proof of authority, and mission-plan event endpoints have no verified publish/receipt history. Paper examples constitute historical exposure; future case selection must be documented and cannot be called strict confirmatory. A rare nominal event can be a transient calibration/reset rather than a persistent reference-worthy regime. That distinction, healthy anchor availability and causal context arrival remain unresolved even with usable retrospective truth.

SWaT/WADI request-only source access remains blocked for this audit. No credential/access restriction bypass, unofficial mirror or derivative used. CARE is a historical lead only, not newly inspected bytes; file identity cannot supply missing operational semantics.

## Why no real route is ready

The strongest L1 lead has source-defined commanded/nominal/fault evaluation potential. Nevertheless a time-indexed retrospective command trace is not a validated causal delivery contract, and labelled rare events are not automatic settled-normal cohorts. No inspected real source has qualified all eight fields for persistent reference admission. Missing evidence, competing explanations and faults during authorization remain unresolved. The selected overall gate is CONTROLLED_CONTEXT_ONLY; this does not assert all real datasets are useless.

Next bounded audit, if authorized: pin ESA release; inspect official metadata/command schema before observations; retain all eligible physical sequences under observation-only feasibility criteria; qualify causal receipt assumptions and source nominal-event eligibility independently of detector outputs. Resolve whether L1 only is sufficient research scope. Do not import events.csv endpoints, command priorities chosen using annotations, target anomaly arrays or rare-event feedback as runtime permission.
