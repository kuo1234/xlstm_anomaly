# P10 / T1 探索性、label-blind CPU 規模試驗（pilot）報告

> **性質：探索性試驗（exploratory scale pilot），不是 sealed gate。** 所有數字皆為 provisional；僅使用 SMD `machine-1-4` 與 `machine-2-1` 的 **train** 檔（從未開啟 test / test_label）；ground truth 全部來自人工注入事件。程式：`p10_pilot.py`（實驗）、`p10_analyze.py`（彙整與作圖）；執行紀錄：`p10_run_log.txt`。

## 0. 設定摘要

- 資料：每台 train ≈ 23.7k 列；前 50% 為 fit 區（再以前 80% 訓練、後 20% 校準殘差尺度 σ），後 50%（≈11.85k 步）為串流區。刪除 fit 區 sd<1e-3 的通道後，machine-1-4 保留 29 通道、machine-2-1 保留 32 通道。通道以 fit 區 z-score（sd 下限 0.02）。注入振幅單位 u_c = 通道一階差分 sd（下限 0.05）。
- 模型（皆為一步預測器 ŷ_{t+1} = z_t + head(·)，score = 以校準殘差 σ 標準化的均方誤差；每個 update step = 1 個時間步）：window_only（MLP，K=8，無跨窗狀態）、lstm（hidden 64）、mlstm（矩陣記憶 16×16，sigmoid 閘）、gdeltanet（naive recurrence）、titans（MLP 記憶，測試時以 ||M(k)−v||² 梯度 + momentum η + decay α 更新）、knn_append（1-NN，K=8 窗，bank 初始 = fit 區窗，每個被評分窗之後 append；排除最近 8 步內 append 的窗以避免 trivial match）。每個神經模型：600 iterations、batch 32×128 步、單一訓練 seed。
- score-before-write：step t 的分數只使用寫入到 z_{t−1} 的狀態。
- 注入：A1/A2 長度 L=30；5 種故障：spike burst（振幅 1u/2u/4u，5 通道，隨機 ±pattern）、corr（6 通道以遠處真實片段取代 → 相關性破壞）、stuck（6 通道凍結）。24 個位置 × 2 台機器 = 48 個 unit（bootstrap 以 unit 為單位，2000 次）。
- 分支：W（A1 寫入）、F_sub（A1 換成他處真實常態片段）、F_sub2（第二個獨立常態片段 = null 對照）、F_skip（狀態凍結）、F_decay（僅衰減，梯度/寫入閘=0；lstm、window_only、knn 不適用）。
- q = A2 窗內最大分數在「該 episode 的 pre-A1 常態分數（長度 30 滑動窗最大值，n≈181）」中的 rank 分位；WIM_sub = q(F_sub) − q(W)；另報連續量 log(s2_W / s2_Fsub)（避免 q 飽和）。q>0.95 視為 5% FPR 下事件被偵測。

## 1. G0：狀態脈衝響應與半衰期（單步脈衝 3u × 8 通道，12 位置/台）

| 模型 | h50（1-4 / 2-1） | h05（降到 5%）（1-4 / 2-1） | 跨窗攜帶？ |
|---|---|---|---|
| window_only | 8 / 8 | 8 / 8 | 否（lag>8 響應恰為 0；確認為無跨窗狀態） |
| lstm | 5 / 4 | 38 / 24 | 是，短（<~100 步） |
| mlstm | 3 / 3 | 54 / 22 | 是，短 |
| gdeltanet | 4 / 5 | 17 / 38 | 是，短 |
| titans | 13 / 92 | 91 / 337 | 是；2-1 上較長且在 lag≥1024 後響應反而上升（見限制） |
| knn_append（分數差） | 7 / 7 | 15 / 7 | 非參數；脈衝只影響相似查詢，對常態查詢 lag>16 影響≈0 |

h 的單位是 update step（lag 1 之響應為基準）。除 titans(2-1) 外，所有參數化記憶的 h05 ≤ ~54 步，h50 ≤ 5 步：**在本訓練設定（128 步序列、零初始狀態）下，這些小模型實際的記憶範圍遠短於 Δ=256、1024。** 圖：`fig_g0_halflife.png`。

## 2. RQ0：持久狀態 vs 逐窗重置（良性漂移，閾值於漂移前 99 百分位凍結）

漂移後 FPR（兩台平均；持久 / 重置；pre-drift 對照 FPR ≈ 0.01）：

| 模型 | level shift 持久/重置 | ramp 持久/重置 | 無漂移對照 持久/重置 |
|---|---|---|---|
| window_only | 0.046 / 0.046 | 0.026 / 0.026 | 0.015 / 0.015 |
| lstm | 0.099 / 0.101 | 0.055 / 0.058 | 0.015 / 0.014 |
| mlstm | 0.135 / 0.095 | 0.052 / 0.039 | 0.015 / 0.015 |
| gdeltanet | 0.259 / 0.268 | 0.124 / 0.129 | 0.013 / 0.014 |
| titans | 0.219 / 0.171 | 0.121 / 0.091 | 0.043 / 0.017 |
| knn_append | 0.027 / 0.092 | 0.023 / 0.047 | 0.019 / 0.018 |

成對差（持久 − 重置，95% bootstrap CI）：knn_append level −0.065 [−0.108, −0.028]、ramp −0.024 [−0.043, −0.008]（**持久有益**）；gdeltanet −0.009 / −0.005（CI 排除 0 但量級可忽略）；lstm ≈ 0；mlstm +0.040 [0.016, 0.071] / +0.013；titans +0.048 [0.012, 0.094] / +0.029，且在**無漂移**時也 +0.027 [−0.001, 0.062]（**持久有害**）。

結論（RQ0）：在此設定中，**沒有任何參數化神經記憶從持久狀態獲益**（mlstm/titans 反而變差）；只有 kNN-append（bank 隨漂移擴充）顯示明確的持久效益。window_only 本身在漂移下 FPR 最低之一（0.046）。所有 forecaster 在 2σ 級位準漂移下 FPR 都明顯高於 1%——因為殘差式預測器的輸入絕對位準超出訓練分布，這與「記憶」無關。模型僅在常態資料上訓練、沒有針對漂移適應做任何訓練，因此這是「現成記憶模型」的結果，不代表經適應訓練的記憶無用。圖：`fig_rq0_fpr.png`。

## 3. RQ1：WIM_sub(Δ)

Δ ≤ 8 時 window_only 也有大 WIM（例：spike_a1 Δ=1 為 0.19；stuck 0.25），因為 A1 尾端仍在其 K=8 視窗內——這是**視窗內污染，不是記憶**，故 **Δ=1、4 不能作為記憶存在的證據**。以下只看 Δ ≥ 16（> K）。

WIM_sub（q 單位，兩台機器 48 unit 平均；完整表與 CI 見 `p10_wim_summary.csv`）：

| fault | 模型 | Δ=16 | Δ=64 | Δ=256 | Δ=1024 |
|---|---|---|---|---|---|
| spike_a1 | mlstm | 0.044 | 0.000 | 0.000 | 0.000 |
| spike_a2 | mlstm | 0.029 | −0.001 | 0 | 0 |
| stuck | mlstm | 0.085（CI [0.018,0.161]） | 0.000 | 0 | 0 |
| corr | titans | 0.014 | 0.004 | 0.017 | −0.005 |
| spike_a4 | knn_append | 0.062 [0.030,0.101] | 0.030 | 0.038 | 0.022 [0.006,0.043] |
| 其餘 lstm/gdeltanet/titans | | |≤0.02，CI 包含 0 | | |

- 神經記憶模型在 Δ≥64 的 WIM_sub 全部 ≈ 0（|WIM| ≤ 0.02，CI 皆含 0）；與 window_only 的成對差（Δ≥16 平均）：僅 mlstm/stuck +0.021 [0.005, 0.040] 的 CI 排除 0（該格 Δ=16 帶來），其餘包含 0。
- 連續量 log(s2_W/s2_Fsub)：mlstm 在 **Δ=16** 對 5 種故障全部顯著為負（−0.15 ~ −0.29，約降低 13–25% 的 A2 分數；CI 排除 0），但 Δ=64 起消失 —— 與 G0 的 h05≈20–54 一致。titans 僅 corr/Δ=256 有 −0.085（CI 上界 −0.000，邊緣）。
- knn_append 僅在高振幅 spike_a4 上有跨 Δ 持久、小幅的遮蔽（q 單位 0.02–0.06；log 比 −0.39→−0.14，Δ=1024 仍 −0.136 [−0.205,−0.083]），不隨 Δ 衰減（bank 不衰減，符合預期），其餘故障上 Δ≥64 近 0。注意 spike_a4 的 q 接近飽和（~0.92）。
- null（F_sub − F_sub2）：各 Δ 的 cell 平均 SD ≈ 0.010 (Δ=16)、0.005 (Δ=64)、0.004 (Δ=256)；但單一 unit 的 null SD 中位 0.022、最高 0.34，故單 cell 的 WIM 在 q 單位上雜訊不小。
- F_skip / F_decay 與 W 的差見 `p10_wim_summary.csv`（wim_skip、wim_decay 欄）；因 F_skip 保留 A1 前狀態，其行為與 F_sub 相近，未發現「衰減路徑 vs 內容路徑」可分辨的差異。

圖：`fig_wim_vs_delta.png`。

## 4. RQ2'：遮蔽核（A2 與 A1 相似度，spike 家族，A1=2u；Δ=16、256）

相異度 ρ = ||δ2 − δ1|| / ||δ1||（注入差分）。10 個變體：振幅 ×0.5/0.75/1/1.5/2、通道重疊 0/50%、pattern 隨機/方波/斜坡。

- Δ=16：mlstm 的 WIM 在各變體上為 0.007–0.043，**對 ρ 平坦**（ρ=0 的 identical 為 0.029，ρ≈1.4 的 pat_random 為 0.043），CI 彼此重疊——沒有可解析的相似度選擇性；其他神經模型 ≤0.02。knn_append 在 Δ=16 於高振幅（×1.5、×2）略高（0.026）、於不同通道/pattern ≤0（本應如 twin-freak 般只遮蔽相似事件，方向與預期一致，但 CI 含 0）。
- Δ=256：僅 titans（0.00–0.02）與 knn_append（×1.5/×2 為 0.010）非零，皆 CI 含 0。
- 因此：**無法判定神經核比 kNN-append 更寬**；觀察到的神經 WIM 小到無法描繪核形（power 不足），沒有證據顯示神經記憶具有 kNN 沒有的、對不相似事件的遮蔽（亦即目前資料不支持「超出 twin-freak 的神經記憶遮蔽」）。核寬度（半高相異度）因 WIM(identical) 的 CI 含 0 而不計算（NA）。圖：`fig_kernel.png`。

## 5. 判讀與建議（provisional）

- WIM：**Δ≈16 為 WEAK（僅 mLSTM，約 13–25% 分數降低但 q 單位 ≤0.085）；Δ≥64 為 ABSENT（神經記憶）**；kNN-append 有小幅持久遮蔽（僅高振幅 spike）。核：**未見比 kNN-append 更寬**。
- RQ0（utility）：持久狀態對現成神經記憶無效或有害（mlstm、titans），僅 kNN-append 獲益。依 P10 的邏輯（持久若無益，現象即無關），這是對 T1 最重要的負面訊號。
- 失敗的原因多半是「記憶範圍短」（h05 ≲ 54 步，訓練序列 128 步）與「記憶未被訓練去承載長期資訊」，而非已證明「寫入可遮蔽」不可能。若要做 sealed T1，需要先用長序列/漂移增強訓練讓記憶範圍達 Δ，否則測得的是訓練設定，不是機制。
- 建議的 sealed margin（草案）：(i) 只在 Δ ≥ 2·K 且 Δ ≤ 4·h05（各模型以 G0 實測 h05 為準）判定；(ii) 主要終點 = 對 window_only 的成對 WIM 差，≥ 0.05（q 單位；≈ 本 pilot Δ≥64 null cell-SD 0.005–0.01 的 5–10 倍、Δ=16 的 5 倍），且 95% CI 下界 > 0，unit ≥ 48（≥ 3 個獨立機器/種子）；(iii) 次要終點 log(s2_W/s2_Fsub) ≤ −0.18（≈ ≥ 16% 降低）。原 T1 的「相對 window_only 多 20% 遮蔽」在 window_only=0（Δ>K）時無定義，建議改為上述絕對差值；(iv) 避免 q 飽和：使用 1u–2u 振幅。(v) 至少 3 個訓練 seed。

## 6. 限制（必讀）

1. 探索性；單一訓練 seed/模型；2 台機器；每格 48 unit，且各 Δ 共用同一組起點，不是獨立重複；24 個起點取自 ≈11.85k 步串流，部分 episode 的基底區段會重疊。
2. 「train 為常態」是假設，未驗證（SMD train 可能含未標記異常）；注入為合成事件，F_sub 取代片段與前後會有不連續；corr/stuck 對殘差式預測器本身很難偵測（q 偏低），其 WIM 的資訊量低。
3. 模型很小、訓練序列 128 步、零初始狀態；串流 >1000 步屬分布外使用。titans 在 machine-2-1 擬合較差（最終訓練 loss 0.05 vs 0.0055；σ 中位數 0.5），其 G0 響應在 lag≥1024 後上升、無漂移時持久 FPR 即偏高——疑為長串流狀態不穩定，G0 的 h 與其 Δ≥256 的結果對 titans 不可靠。
4. Δ 以 update step（=時間步）計，未換算實際時間（資料無 timestamp）；h 以 lag=1 響應為基準；window_only 的 h=K。
5. q 對強故障飽和（spike_a4 q≈0.92），kNN 採 1-NN 並有 8 步排除區（Δ≤8 的 kNN 結果受其影響）。
6. F_decay 僅適用於 mlstm、gdeltanet、titans；漂移實驗只有 level shift 與 ramp（2σ，8 通道），未做閾值自適應基線。
7. 本任務範圍僅為 pilot；p10_occupancy_audit、p10_decision_memo、GitHub issue/分支未在此任務產出。
