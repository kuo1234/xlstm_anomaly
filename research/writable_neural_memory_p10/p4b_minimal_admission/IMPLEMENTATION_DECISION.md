# P4-B implementation decision, before model outcomes
Issue #18 GO is only a minimal common causal admission pilot. Prior inspected repo candidates: p10_gl1_models.py includes recurrent backbones prohibited here and a larger window-only MLP; phase_d_backbone.py uses official GPU MLP/SANA with D8/window10 and externally initialized M0 state; real_data_r0_models.py contains prohibited recurrent builders. Reusing these would add capacity and dependencies unnecessary for this timing question. No candidate was trained or evaluated on B to make this choice.

Choose a new compact linear bottleneck autoencoder (4→2→4), deterministic train-only SVD encoder, train-only least-squares decoder, fixed A-only scaler, current-point history1. This has a visible 2D latent and continuous mean-squared reconstruction score. Only the 3×4 decoder (including intercept;12 coefficients) can change. Encoder/scaler/calibration/reference remain frozen. All adaptive arms use precisely the same one-step mean-loss SGD decoder operator, fixed learning rate .01, no momentum/decay/optimizer persistent state. No gradient clipping, training search, best checkpoint or representation rescue. Closed-form initial fit and deterministic updates have no model/optimizer RNG, so one deterministic technical replicate is sufficient; physical N remains5. No fabricated seeds are counted as replicates.

Rank2 is a prospective minimum nontrivial bottleneck, not selected on B; both score and latent use the pre-update model/scaler. Threshold is A-calibration99th percentile. An underexpressed new-normal problem must fail without architecture change. The model does not observe regime time/seed/truth. Initial fit/cal arrays alone are passed to training.

This is mechanism-matched selective adaptation on a common low-capacity reconstruction model, not official M2N2/CANDI reproduction or general backbone superiority. PCA encoder is fixed; updating only decoder may constrain attainable adaptation, and retention may be harmed by fitting a new mean. These are testable limitations, not reasons for post-hoc rescue.

Native official paths are NOT_RUN: they would add GPU/backbone/normalizer/adapter capacity and incompatible inference order. TSB is NOT_RUN this pilot: real admission timing cannot be evaluated. P4-A generator/truth and all15 streams reused unchanged; semantic twins remain primary reported impossibility control.
