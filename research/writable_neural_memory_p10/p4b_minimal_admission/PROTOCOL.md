# Pre-result P4-B protocol
Authority: Issue #18 and configs/pilot.json; P4-A timing/truth/metrics unchanged. Scientific N=5 physical groups; all3 paired arms ×9 policies =135 trajectories. One deterministic model per physical group, no model RNG/optimization RNG. No outcomes choose architecture, threshold, Q, schedule, or seeds.

Architecture follows IMPLEMENTATION_DECISION.md: train-only SVD rank2 encoder, train-only least-squares decoder, history1; mean-squared reconstruction continuous score, frozen A99% tau. All actual writes are a single stateless mean-loss SGD decoder step, lr=.01. No extra mutable normalizer/scaler/reference/calibrator. Encoder and latent representation are fixed. Tiny analytic model replaces prohibited or larger repo builders; no official reproduction claims.

Candidate: each pre-update score>tau. Consecutive alarms count; a single non-alarm clears candidate/release (gap0). Q={1,64,128,256,512} all primary, never choose best Q for table. On first Q-th alarm: formal PROMOTE current point only, then UPDATE current high-score points until reset. Earlier evidence points are never backfilled. This is intentionally a minimal duration filter with no feature validation; retaining whole candidate would add replay/contamination and unequal update batch size. Record current-only exposure and all candidate starts/resets. IMMEDIATE_UPDATE matches Q1 mutations with UPDATE instead of formal PROMOTE, so Q1 is a mandatory operator parity control.

M2N2-style predicted-normal score gate updates current point only. CANDI-style A-calibration latent Mahalanobis selection has frozen high-score-normal references (top .5%, cap32) and interquartile references (cap32); chi-square lower .05 quantile with df2, covariance ridge1e-6; separate hard-high and moderate-below-threshold buffers16. Flush mean-SGD at16, no final flush. Pending points are distinct from actual weighted loss exposure. No test labels, buffer leakage into scores or reference mutation.

Per point: observe -> score/hash/latent immutable -> decision -> update -> post-state hash. Runtime accepts only one observation/time at a time, initial fit/cal model, and policy config. No semantic IDs, physical seed, schedule or truth. Raw trace includes selection, buffer entry/exit and pending counts, candidate start/count/reset, PROMOTE, weighted IDs, parameter hash before/after, and explicit zero/not-present markers for every other mutation path. No rollback; NOT_IMPLEMENTED.

All source observations/initial train+cal paths are hashed against P4-A. Raw ledgers/checkpoints remain ignored on ssh kuo, ledger schema/manifests/hash evidence tracked. Freeze implementation+metrics+tests, commit/push and verify remote SHA before any A fit or stream result. Full run trace seal is pushed before evaluator loads normative arrays. Historical P4-A truth was already exposed; do not claim strict label blindness or confirmatory data. Runtime remains truth-isolated.
