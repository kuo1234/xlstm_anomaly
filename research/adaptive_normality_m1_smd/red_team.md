# M1-A red-team review

This review lists failure paths before execution and fixes the interpretation or stop condition prospectively.

| Attack | Risk class | Why it matters | Prospective response |
|---|---|---|---|
| Forecast residual may be no better than first difference | RESOLVABLE_BY_EXPERIMENT | Last-value MSE equals squared first difference; a neural forecast that only reproduces persistence has no case as the core signal. | Include it as a mandatory cheap control; xLSTM must clear the per-machine AP gain or fixed complement gate. Otherwise FORECASTING_NOT_JUSTIFIED. |
| An anomalous segment can become predictable after entering the context | FATAL_IF_TRUE for forecasting as sole signal | A persistent shifted sequence may be forecast well once its pattern is in the W=256 input. | M1 reports score behavior on event segments and onset/recovery but does not solve this mechanism. If this erases useful detection at the preregistered event/FPR gate, stop; any later adaptation work needs separate onset/context contamination tests. |
| Preprocessing may dominate detector ranking | RESOLVABLE_BY_EXPERIMENT | R0’s zero-std-only scaler caused an extreme near-constant-channel path. | Freeze robust train-only scale and clipping before scores; no post-hoc rescaling. Interpret gains as conditional on this fixed transform. |
| Context choice may leak anomaly information | RESOLVABLE_BY_EXPERIMENT | Choosing W from labeled events could inflate reported gains. | W=256 was selected from first-70%-train ACF only. No test-label-informed change is permitted. Daily-scale peaks remain outside this context. |
| Reconstruction may outperform forecasting | RESOLVABLE_BY_EXPERIMENT | Forecasting is not guaranteed to be the better anomaly objective. | xLSTMAD-R is a required comparator. If it is stronger and forecast gives no fixed incremental gain, forecast fails the gate. |
| Matched LSTM may equal xLSTM | NOVELTY_THREAT | That would support a possible generic forecasting result but not a special xLSTM contribution. | Require a separate replicated xLSTM-vs-LSTM claim; equality explicitly removes the xLSTM-specific claim. |
| Event metrics may disagree with AP | RESOLVABLE_BY_EXPERIMENT | Rare point spikes may improve AP without detecting incidents; threshold burden can also disagree. | Gate includes both machine-level AP and event detection/FPR; report onset delay, false-positive burden, and recovery. No single metric substitutes for the others. |
| One machine may dominate a pooled or mean result | RESOLVABLE_BY_EXPERIMENT | SMD machines have unequal prevalence, event counts, and dynamics. | Each machine is the unit, macro AP is equal-weighted, paired bootstrap resamples machines, all per-machine values are shown, and win/catastrophe limits are fixed. |
| Source-native success may say nothing about transfer | SCOPING_LIMITATION | Fitting every detector independently to each machine is not cross-machine transfer. | Keep transfer out of the claim and experiment; require a separate held-out-machine protocol. ZERO_SHOT_NOT_STARTED. |
| Dominant normal spectral peaks are longer than W=256 | SCOPING_LIMITATION | The selected context covers typical ACF decay but not the roughly daily spectral scale. | State that M1 tests local subdaily one-step forecasting only. A negative result does not kill all seasonal forecasting methods. |
| SMD train is assumed normal, not independently labeled | SCOPING_LIMITATION | Contamination in train can bias learned models, scale estimates, and calibration. | Report the benchmark assumption. No unlabeled row may be called independently verified normal. |
| Channel indices may not have common meanings across machines | SCOPING_LIMITATION | Cross-machine channel pooling would assume unsupported semantics. | Fit each machine independently and preserve within-machine ordering. No cross-machine parameter sharing occurs in M1. |
| No persistent state is tested | SCOPING_LIMITATION | This study cannot tell whether state carried across windows helps or contaminates. | Reset state per window and reserve persistence for a distinct, separately gated study. |
| All test channels are transformed before labels are read | RESOLVABLE_BY_EXPERIMENT | Even unsupervised test inspection can influence subjective choices. | Transform is frozen from train-only stats; numerical clipping audit does not change it and labels are evaluator-only after score sealing. |
| Point-label contiguous runs may not match incident identities | SCOPING_LIMITATION | Event rates and delays are only label-run proxies. | Publish point metrics as primary and event metrics with this limitation; do not call runs ground-truth incidents. |
| Current R0 internal-state negative result may imply recurrent features add no value | NOVELTY_THREAT | The new detector might add complexity without observable benefit. | M1 tests the separate operational forecast-residual signal against simple controls. Failure blocks forecasting as the adaptive project’s core signal. |
| Model/runtime mismatch at W=256 may make the budget unusable | RESOLVABLE_BY_EXPERIMENT | R0 timing is W=64 reconstruction, not a measured W=256 forecaster. | Budget is an upper-envelope estimate with 25% reserve; no silent reduction in cohort/config. Re-estimate only with a separately authorized implementation-level timing preflight that does not inspect anomaly metrics. |

## Central kill condition

If neither the xLSTM one-step residual alone nor the frozen forecast-plus-control fusion clears the machine-level AP gain, event detection, false-positive, and catastrophic-machine requirements in protocol.md, classify the result as FORECASTING_NOT_JUSTIFIED. Do not proceed to adaptive-normality experiments with forecasting as the core signal.

A result where only LSTM-F passes is an architecture-agnostic reframe, not an xLSTM result. A result where AP passes but event/FPR checks fail does not pass. A pooled metric cannot rescue a failed per-machine gate.
